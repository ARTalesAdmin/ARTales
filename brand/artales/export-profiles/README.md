# ARTales export profiles

This directory defines the controlled profiles for future exports from the locked ARTales symbol, wordmark, and light/dark logo lockup masters. It contains a specification only; it does not contain production exports.

The `primary-light` and `primary-dark` profiles remain the two main brand lockups. Monochrome dark, Ink/Night, Paper, white, and other one-color treatments are practical secondary export profiles, not additional primary logos.

The small-size symbol is only a candidate base. Favicon and app-icon work requires a separate review, including a decision on simplified geometry and any controlled square background, before production files can be approved.

No file in this directory approves runtime use. SVG/PNG/ICO production files, favicon and app-icon candidates, and all `public/` or runtime integration must be created in later, explicitly scoped pull requests after human review.

The machine-readable specification is [`artales-export-profiles.v0.1.json`](./artales-export-profiles.v0.1.json). The accompanying review report is [`docs/ARTALES_BRAND_EXPORT_PROFILES_V0_1.md`](../../../docs/ARTALES_BRAND_EXPORT_PROFILES_V0_1.md).
