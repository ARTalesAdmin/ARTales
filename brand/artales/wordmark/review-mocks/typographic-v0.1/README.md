# ARTales typographic wordmark mock v0.1

## Review status

This directory contains a **review-only typographic mock** of the word “ARTales”. Its status is
`review_only`, its approval state is `awaiting_human_visual_review`, and it is explicitly
`not_master: true`, `not_lockup: true`, and `publicIntegration: false`.

No wordmark is approved. This workspace does not create a wordmark master, final candidate,
light/dark lockup candidate, or lockup master. The locked standalone symbol master remains
unchanged and is not included in the mock.

## Font strategy and provenance

The SVG uses live text with the placeholder system-font stack
`Georgia, 'Times New Roman', Times, serif`. This is a generic fallback strategy for reviewing a
broad literary/editorial direction; it is not the selection or endorsement of a specific
font. No font file is committed, vendored, embedded, downloaded, or externally referenced.
No specific font license is claimed.

The first available font in the stack is selected by the viewer, so letter shapes, metrics,
kerning, spacing, and placement can vary between environments. The artifact is not an outline
master. Converting text to outlines requires a later, separately approved task after an exact
font, version, source, license, and permitted logo use have been confirmed.

## Human review

Review letter character and literary/editorial feel, readability, distinctiveness, potential
fit next to the locked symbol, uppercase/lowercase balance in “ARTales”, and kerning and
spacing. Reviewers must also decide whether the licensing approach is acceptable, whether the
direction may proceed to a real wordmark candidate, whether later outline creation may be
authorized, and whether later light/dark lockup candidate preparation may proceed.

Reviewing this artifact does not itself grant any of those approvals.
