# ARTales logo lockup master v1

This directory is the locked ARTales logo lockup master v1 package. It contains
light and dark SVG masters with transparent backgrounds, copied byte for byte
from the human-approved v0.3 review candidates.

Human approval: **“Ano, to je ono.”**

The source symbol and wordmark masters remain unchanged. Both lockups contain
outlined vector geometry: no live text, external font reference, raster image,
or installed font is required to render them.

This lock does not approve runtime, application, website, or public asset
integration. Export profiles, production exports, favicons, app icons,
monochrome treatments, and other small-size variants remain separate future
work requiring explicit review and approval.

The JSON manifest records provenance, hashes, approval state, palette intent,
scope limitations, and the byte-identical source-to-master confirmations.
