# ARTales SVG Candidate Masters

This directory contains early SVG/vector candidates for the ARTales visual identity.

These files are intentionally **not locked production masters**.

They are working candidates created from the approved visual direction and the current generative AI logo references. Their purpose is to provide a clean, inspectable, versioned starting point for visual review and later refinement.

## Current files

- `symbol-pen-drop.v0.1.svg` — standalone pen/drop symbol candidate.
- `logo-lockup-light.v0.1.svg` — primary logo lockup candidate for light / paper backgrounds.
- `logo-lockup-dark.v0.1.svg` — primary logo lockup candidate for dark / ink backgrounds.

## Confirmed direction

The candidates follow the six approved ARTales Visual Pack v0.1 decisions:

1. Primary symbol = gold pen / drop.
2. Primary logo = symbol on the left + ARTales wordmark on the right.
3. Dark variant = gold on dark.
4. Light variant = gold symbol + dark wordmark on warm paper.
5. Monogram = reserve candidate, not primary mark.
6. Texture = presentation layer, not production master.

## Important limits

The current wordmark is still text-based and uses a candidate serif stack. It is not yet a final custom lettering master.

The symbol is a simplified construction based on the references. It should be visually compared against the original direction before being promoted.

The gold gradient is included for visual review. A flat single-color master may still be needed later.

## Promotion path

A candidate can only move toward `locked_master` after:

- visual review against the original references,
- dark and light background checks,
- small-size checks,
- clear-space and minimum-size rules,
- wordmark font/licensing or outlined lettering decision,
- acceptance by the project owner.
