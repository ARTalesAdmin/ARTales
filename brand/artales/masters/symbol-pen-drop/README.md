# ARTales standalone symbol master

This folder contains the locked master assets for the standalone ARTales pen/drop
symbol. Master v1 was locked from the human-approved `smoother` candidate without
changing its SVG geometry.

The presence of this master does not imply runtime or `public/` integration. It does
not approve favicons, app icons, a small-size variant, a wordmark, or a logo lockup.
Derivative exports and any runtime usage must be proposed, reviewed, and delivered as
separate controlled steps.

## Files

- `symbol-pen-drop.master.v1.svg` — byte-identical copy of the approved candidate SVG.
- `symbol-pen-drop.master.v1.json` — lock status, provenance, approval, and scope
  boundaries for master v1.

The source candidate remains at
`brand/artales/candidates/symbol-pen-drop/symbol-pen-drop.smoother.candidate.v0.1.svg`,
with its source metadata alongside it.
