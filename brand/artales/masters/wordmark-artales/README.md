# ARTales standalone wordmark master v1

This directory contains the locked standalone ARTales wordmark master v1. It was
locked from the human-approved Option A outline candidate without changing the
candidate SVG.

The SVG contains outline geometry rather than live text, so no font is needed to
display it. The source typeface remains recorded as Libre Baskerville Regular,
licensed under the SIL Open Font License 1.1, so the wordmark's provenance stays
traceable.

This is a standalone wordmark, not a full logo lockup. The ARTales symbol is not
included. This lock does not approve runtime or `public/` integration, light/dark
lockups, exports, favicons, or app icons.

## Files

- `artales-wordmark.master.v1.svg` — byte-identical copy of the approved outline
  candidate SVG.
- `artales-wordmark.master.v1.json` — master status, approval, provenance,
  checksums, and scope boundaries.

The source candidate and its metadata remain in
`brand/artales/wordmark/candidates/option-a-outline-v0.1/`.
