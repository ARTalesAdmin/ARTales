# ARTales micro symbol master

This directory contains the locked ARTales micro symbol master v1. The SVG is a
byte-identical copy of Candidate B from the reviewed micro candidate set. Candidate B
was selected as the most practical direction for very small icon contexts, especially
at 16px–20px.

This size-specific master is derived from the locked standard ARTales symbol master,
but it does not replace that normal symbol. Use the standard symbol master outside
contexts that specifically require a simplified micro treatment.

The package is a source master lock only. It is not a production favicon or app icon,
and it is not integrated into `public/`, the application, or runtime metadata. PNG,
ICO, app-icon, and other production export files will be created and integrated only
in later, explicitly scoped work.

## Files

- `artales-micro-symbol.master.v1.svg` — byte-identical copy of the approved Candidate
  B SVG.
- `artales-micro-symbol.master.v1.json` — provenance, approval, checksums, intended use,
  and scope boundaries for master v1.

The source candidate and candidate-set metadata remain unchanged in
`brand/artales/small-size/micro-candidates/v0.1/`.
