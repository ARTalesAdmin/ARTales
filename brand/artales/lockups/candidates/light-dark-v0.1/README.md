# ARTales light/dark lockup candidates v0.1

These two horizontal lockups are **review-only candidates**. They place the locked standalone symbol master to the left of the locked standalone wordmark master. The source path geometry is copied inline so each SVG is self-contained; neither source master is modified or regenerated.

## Candidate files

- `artales-lockup-light.candidate.v0.1.svg` — locked gold symbol with Text Dark wordmark, intended for Paper (`#FDF3E2`).
- `artales-lockup-dark.candidate.v0.1.svg` — locked gold symbol with Primary Gold wordmark, intended for Deep Dark (`#141414`) or Ink Night (`#0F1315`).
- `artales-lockup-light-dark.candidate.v0.1.json` — provenance, composition parameters, limitations, and review state.

Both candidate SVGs have transparent backgrounds. They contain outlined geometry rather than live text, embedded images, external references, or runtime font dependencies.

## Review status

These files are not lockup masters, runtime assets, or public assets. Their status is `lockup_candidate_review_only`, their approval state is `awaiting_human_visual_review`, and they must not be treated as approved brand exports.

Human review should focus on:

1. spacing between symbol and wordmark;
2. relative scale and whether the symbol feels appropriately restrained;
3. optical vertical alignment;
4. the light and dark color relationships; and
5. readability at representative lockup sizes.

Export profiles, PNG derivatives, favicons, app icons, and any website integration come later, after explicit lockup approval and separately scoped work.
