# ARTales micro symbol candidates v0.1

This folder contains review-only derivatives of the locked ARTales pen-drop symbol master for human comparison at 16px, 20px, 24px, and 32px. The work answers the existing review finding that the standard direction is acceptable from 24/32px upward but is not reliably recognizable at 16px.

## Reference-first boundary

Every candidate reuses the locked master outer silhouette without modification. Only the small interior feature is strengthened or simplified; this is controlled optical reduction, not a redesign. The canonical source remains:

`brand/artales/masters/symbol-pen-drop/symbol-pen-drop.master.v1.svg`

## Candidates

- **A — closest to master:** retains all four interior lozenges and thickens them slightly.
- **B — strongest 16px reduction:** replaces the four subdivisions with one enlarged central diamond.
- **C — balanced reduction:** uses three enlarged lozenges and removes the lowest subdivision.

Use `artales-symbol-micro-review-board.v0.1.svg` for side-by-side review on light and dark fields. The displayed marks have exact 16px, 20px, 24px, and 32px bounding-box heights.

## Status and restrictions

All files are `review_only` and await human review. None is a locked micro master, favicon, export source, or public/runtime asset. Do not copy these files into `public/`, generate ICO/PNG output, or integrate them into app code without a separate explicit approval.
