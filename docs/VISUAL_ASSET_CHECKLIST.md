# Visual Asset Checklist

This checklist explains what ARTales still needs before a visual identity can be locked as a production-ready Visual Identity Pack v1.

It is written for non-designers and should be used before generating final assets or tokenizing the website.

## 1. Primary wordmark

Decide which ARTales wordmark is the main one.

The wordmark is the written ARTales logo. Raster previews are useful, but the final source should be a vector master.

Needed before lock:

- selected primary wordmark;
- SVG vector master;
- light and dark usage variants;
- transparent export plan.

## 2. Logo lockup

Decide which combination of symbol plus wordmark is the primary logo lockup.

Needed before lock:

- primary lockup;
- secondary lockup if needed;
- SVG vector master;
- clear space rule;
- minimum size rule.

## 3. Symbol or mark

Decide whether the standalone symbol is official and where it may be used.

Needed before lock:

- approved symbol;
- SVG vector master;
- usage rules;
- prohibited transformations.

## 4. Monogram

Decide whether the AT monogram is official and whether it should be used for small icons.

Needed before lock:

- approved monogram;
- SVG vector master;
- small-size legibility check;
- favicon and social avatar suitability decision.

## 5. Vector masters

Vector masters are the technical originals used for export.

A JPG or PNG is like a picture of the logo. An SVG is closer to the actual source logo that can be scaled, inspected and exported reliably.

Needed before lock:

- wordmark SVG;
- logo lockup SVG;
- symbol SVG if used;
- monogram SVG if used.

## 6. Transparent variants

Transparent variants allow the logo to sit on different backgrounds without carrying an unwanted rectangle behind it.

Needed before lock:

- transparent wordmark for dark background;
- transparent wordmark for light background;
- transparent symbol;
- transparent monogram.

## 7. Color palette and roles

Confirm exact colors and their purpose.

A color is not ready only because it looks right. It needs a value and a role.

Needed before lock:

- exact HEX values;
- semantic roles;
- contrast notes;
- accessibility notes;
- rule that gold is an accent, not a broad surface.

Example roles:

- ink background;
- paper background;
- gold accent;
- graphite text;
- mist divider;
- white text on dark.

## 8. Typography

Choose fonts for the website and identity materials.

Needed before lock:

- heading font;
- body font;
- UI/control font if different;
- fallback stack;
- license note;
- basic scale and usage notes.

## 9. Clear space and minimum size

The logo needs breathing room and a smallest allowed size.

Needed before lock:

- clear space rule around the wordmark and lockup;
- minimum width for the logo;
- minimum size for symbol and monogram;
- small-use recommendations.

## 10. Export profiles

Define what files should be generated from the masters.

Possible profiles:

- web header logo for dark background;
- web header logo for light background;
- favicon;
- app icon;
- social avatar;
- social sharing image;
- watermark;
- brand sheet.

Each profile needs:

- source master;
- format;
- size;
- background suitability;
- destination path;
- naming rule.

## 11. Do-not-use rules

Define what must not happen to the visual identity.

Examples:

- do not stretch the logo;
- do not recolor gold by eye;
- do not add random shadows;
- do not put the logo on noisy backgrounds;
- do not use generative reinterpretations as masters;
- do not create new variants without versioning.

## 12. Brand sheet

Create one visual reference sheet after the core elements are approved.

It should show:

- primary logo;
- symbol;
- monogram;
- color palette;
- light and dark examples;
- typography;
- basic usage notes.

The brand sheet is an output. It does not replace source masters.

## 13. Approval record

Before final lock, record who approved the visual identity and when.

Needed before lock:

- approval owner;
- approval date;
- pack version;
- list of locked masters;
- list of approved export profiles;
- known limitations or deferred items.

## ARTales current practical status

Available:

- strong cultural and visual direction;
- logo and symbol references;
- dark and light mood references;
- draft palette direction;
- wider brand and message context.

Still missing before Visual Identity Pack v1:

- selected primary logo and secondary variants;
- vector masters;
- transparent exports;
- final color token roles;
- typography;
- clear space and minimum size rules;
- export profiles;
- do-not-use rules;
- brand sheet;
- explicit approval record.
