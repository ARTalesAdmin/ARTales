# ARTales complete illustration capture and Ivana's visual choice

The original image must be captured as actual **binary bytes**, not a URL, a catalogue note, a model-generated description, or the 1×1 QA GIF. Store each raw original by SHA-256 under a **private** content-addressed path in `artales-source-archive`; verify readback SHA-256, size and media type, preserving source URI, Gutenberg book number, artist, timestamp and EU/US rights judgement. Images may be captured despite uncertainty; protected images must not be publicly served or published. Exact byte hashes must remain unchanged even when newer custom illustrations replace them.

`artales-images` already exists but is **public**, allows only JPEG/PNG/WebP, and has a 5 MB object cap: DO NOT put any unknown-rights Gutenberg GIF there. GIF originals belong in private archive. Export an approved web-safe PNG/WebP derivative only when source copyright and visual editor choice allow it; own ARTales cover is always independent and never inherited from Gutenberg.

**Ivana's choice**, per stable component ID/source text anchor: `original`, `custom`, `omit`. Original requires independently verified and safely derived public file. Custom requires original ARTales work and its own review. Omit keeps source snapshot and anchor for future replacement. Text may advance if illustration is omitted. Visual selection NEVER sets publication authorization; editorial approval and signed Reader release remain separate.
