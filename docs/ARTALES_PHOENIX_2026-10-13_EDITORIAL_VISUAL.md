## Essential new product decisions

**Read this first:** [ARTALES_EDITORIAL_VISUAL_QA_STYLE_POLICY_2026-10-13.md](./ARTALES_EDITORIAL_VISUAL_QA_STYLE_POLICY_2026-10-13.md). This durable *design* records the architect's approved direction, acceptance examples and boundaries; none of the new policy entities or publication behavior is implemented yet.

- Visuals **optional per title**, default text-only; policy choices text_only / illustrated_together / visuals_later, changeable by a new audited revision. Final artwork can be entirely absent. Source illustrations captured/legally screened independently. ARTales always authors own covers; Ivana may choose recreate/new/original legally eligible/omit; source ≠ published asset. Recreating by slight changes does not automatically resolve copyright.
- If artwork is ready ahead of release: **one combined final text+visual QA**, not redundant textual QA. If added after text publication: **targeted visual QA** + full automated regression + expanded manual QA only if text anchors/layout/reader position genuinely affected. Text revision stays unchanged. QA binds exact text/visual/style/layout version tuple.
- Existing editor function must be preserved: `note` = public reader block, `editor_note` = internal block annotation, `footnote` = public footnote. New semantic v2 needs full mapping. Editor may see comment as a card/block; storage metadata for internal notes stays outside public source atoms and Reader.
- Existing block formatting (legacy presets/CSS and typography) is **the baseline** for semantic block defaults; preserve inline bold/italic, indent etc. Version global style profile, support local per-title/per-block overrides. Approved releases **pin style version**. Never retroactively restyle old works automatically; a request for global change escalates to architect, default future titles only. Precompute blast radius before optional legacy migration; avoid 100 pointless re-QAs.
- Semantic natural language block correction: immediate local preview, authoritative Save makes immutable revision, notifications on meaningful transitions, not keystrokes. Third old-Reader comparison panel is **optional / undecided**; if used in bootstrap, read-only and not a second source of truth.
- Gallery migration is per work after source legal scan, candidate snapshot, editor approval; old Reader and progress/notes remain until independent authorized cutover. AI only decides semantics at composition/revision time, not at each font-size change; pagination deterministic locally, preset cache possible; offline download not completed.
