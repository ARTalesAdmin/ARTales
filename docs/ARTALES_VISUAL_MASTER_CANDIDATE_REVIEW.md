# ARTales Visual Master Candidate Review

This review guide belongs to the first SVG candidate master set for ARTales Visual Pack v0.1.

The SVG files are not final production masters. They are a first clean construction pass meant to be compared against the current generative AI visual references.

## Files under review

- `brand/artales/masters/candidates/symbol-pen-drop.v0.1.svg`
- `brand/artales/masters/candidates/logo-lockup-light.v0.1.svg`
- `brand/artales/masters/candidates/logo-lockup-dark.v0.1.svg`

## Review goal

Decide whether the first SVG candidates are close enough to the approved direction to continue refinement, or whether the shape needs to be rebuilt more faithfully.

Do not review them as final brand assets.

## What should remain true

The candidates should preserve these approved decisions:

1. The primary symbol reads as a gold pen / drop.
2. The primary logo uses the symbol on the left and the ARTales wordmark on the right.
3. The dark version is gold on dark.
4. The light version is gold symbol + dark wordmark on warm paper.
5. The monogram remains a reserve candidate.
6. Texture remains a presentation layer, not the master.

## Symbol review checklist

Check whether the symbol:

- still feels like the reference pen/drop,
- is vertically balanced,
- has enough elegance and literary/cultural character,
- does not feel too technical, too religious, too fantasy, or too generic,
- has a readable central diamond detail,
- keeps a useful lower drop/point motif,
- remains recognizable at smaller sizes,
- can plausibly become a favicon/avatar base after refinement.

## Logo lockup review checklist

Check whether the lockup:

- has the right relationship between symbol and wordmark,
- feels calm and literary,
- keeps enough space between symbol and text,
- is legible on light/paper backgrounds,
- is legible on dark/ink backgrounds,
- does not look like a SaaS logo, marketplace logo, or fantasy game mark.

## Wordmark caveat

The wordmark in the first SVG candidates is text-based and uses a candidate serif stack:

```text
Cormorant Garamond, Playfair Display, Georgia, Times New Roman, serif
```

This is a placeholder direction, not a locked typographic master.

Before production use, ARTales still needs one of these decisions:

- identify and license the intended wordmark font,
- redraw the wordmark as custom lettering,
- or choose an approved open/licensed typeface and convert the final wordmark to outlines.

## Color caveat

The first candidates use the current candidate palette:

```text
Ink / Night:  #0F1315
Deep Dark:    #141414
Paper:        #FDF3E2
Text Dark:    #272827
Primary Gold: #E0AA47
Warm Gold:    #E3AA46
```

These are still candidate values. They should be tested before being promoted into final tokens.

## Possible review outcomes

### Accept for refinement

The shape is close enough. Continue with spacing, wordmark, color and export refinement.

### Request shape revision

The idea is correct, but the symbol or lockup needs to better match the references.

### Reject candidate

The SVG construction drifts too far from the approved direction and should be rebuilt.

## Not in scope yet

This review does not include:

- favicon export,
- app icon export,
- social avatar export,
- production asset replacement,
- CSS tokenization,
- website runtime changes,
- homepage/header integration.
